Automatic resync

Refresh all configured connections in the background, even when no browser is open. This setting is shared across the deployment.

Use a duration such as 30m, 1h, or 2h30m. Minimum 1m. Default 1h.

The interval starts after each completed refresh, including manual refreshes. Changes apply immediately.

Telegram notifications

Send a summary when a complete resync finds new, updated, or removed alerts. Local risk acceptance does not send a notification.
